What is a Network?

Network hiya:

A group of interconnected devices that communicate and exchange information using agreed communication rules called protocols.

Bdarija b simple:

Network hiya wa7d lwasila katkhlli juj aw ktar mn devices ytsifto data l b3dyathom.

Had devices maykounoch ghir computers.

Y9dro ykono:

  • Desktop
  • Smartphone
  • Server
  • Printer
  • Smart TV
  • Camera
  • Router
  • IoT Devices

Kol wa7d mn hadchi y9dr ykoun node f network.

4. Protocols

Protocol.

Examples dyal protocols li ghadi tsanto f had series:

  • TCP/IP — l’protocol li kaydir base dyal Internet kamel.
  • HTTP/HTTPS — l’protocol li kayst3mlo browsers bach yjibo web pages.

Kola Device 3ndha Address

Bach juj devices y9dro yhadro m3a b3dyathom, khass kol wa7d ykoun 3ndo address — bhal number dyal telephone aw adresse dyal dar.

F networking kaynin jouj addresses asasiyin:

IP Address

Bhal l’adresse dyal dar dialk.

Kayb2an ykoun unique (aw ghaliban unique) f network, o howa li kayst3mlo router bach y3ref fin ghadi ysift data.

Example: 192.168.1.10

MAC Address

Bhal l’ID Card dyal device — mrbota m3a l’hardware nafso (network card).

Kayst3mlo switch bach y3ref chkoun howa had device f local network.

Example: A4:C3:F0:85:AC:2D

⚠ 3lach hadchi muhim f Cybersecurity?

Bzaf dyal attacks classiques (ARP Spoofing, IP Spoofing, MITM) kaykhdmo b l3ab b had addresses — attacker kaykdb 3la network belli howa IP wla MAC dyal wa7d akhor bach y3trd traffic. Ila ma fhmtich addressing mn daba, ghadi ykoun s3ib tfhem had attacks mn b3d.

Trust Boundaries — Machi Kolchi Kif Kif f Network

Point muhim li beginners ghaliban kaynso:

Machi kol device f network 3ndo nafs l’access.

Example dyal Company Network:

  • Guest Wi-Fi — 3ndha access l Internet biss, ma ymknhach t7bet 3la servers dyal company.
  • Employee Network — 3ndo access l internal tools (email, files…).
  • Server Network — mahsora bzaf, ghir IT/Admins y9drو ydkhlo.

Had fikra dyal “faslin bin l3a2ilat” katsma Network Segmentation, o hiya wa7d mn aham defenses f Cybersecurity: ila attacker dkhel mn Guest Wi-Fi, ma ykounch 3ndo access direct l servers hssasin.

Ghadi nt3m9o fiha f articles jayin.

Attack Surface — 3lach Kola Device Zayda = Risk Zayd

F Cybersecurity, kayn concept smito Attack Surface.

Bibasata: kola device jdida li katdkhol l network…

= wa7d l’bab jdid li ymkn attacker ydkhel mno.

Printer 9dema , Camera IoT default config، Smart TV b default password…

Kolhom ymknhom ykono l’weak point f network kamla, even if l’PCs mafehom ta misconfig.

💡 Takeaway: Kbar l’network = kbar l’Attack Surface. Had l’idea hiya li katkhli companies ydiro inventory dyal kola device li connecti, o ysdo access li ma khassoch ykoun maftou7.

Why Networking Matters in Cybersecurity

Key Takeaways

  • Network hiya majmo3a dyal devices mrbotin m3a b3dyathom.
  • Lhadaf howa communication.
  • Protocols homa lqawanin li kaynademo had communication.
  • Kol device 3ndo IP Address o MAC Address bach y3ref o yt3rf m3a b3dyathom.
  • Internet howa network dyal networks.
  • Client kaytlb service, Server kay9dm service.
  • Peer-to-Peer kaykhlli devices ydiro communication directly.
  • Machi kol network segment 3ndo nafs l’access — Trust Boundaries.
  • Kola device zayda f network = Attack Surface zayda.
